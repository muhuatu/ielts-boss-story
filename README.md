# 霸總雅思單詞

用 100 個霸道總裁故事背雅思單詞的手機互動學習網頁。

## 功能
- **今日**：每天固定的任務清單。① 先複習到期的單詞；② 再學新段落，達到每日新詞目標（可設 10、20、30 或 50）；③ 選做弱點加強。畫面上只有一個「開始」按鈕，指向下一件事。
- **複習排程**：依記憶曲線安排複習（1、2、4、7、15、30、60 天）。複習時是真的作答，不是自己評分。單詞等級越高，題目越難，從選擇題、同義替換、故事填空，一路到拼寫和聽音拼字。答錯的單詞會降回第一級，想太久才答對的會提早再複習。
- **故事按段落學**：每段四步，依序是閱讀、單詞卡、遮住中文回想、小測驗。小測驗 80 分通過後才進到下一段。
- **單詞資料**：每個單詞都有故事原句、英文例句、詞性、詞族、常用搭配、同義和反義字、易混淆字，以及雅思話題分類。
- **單詞**：可以搜尋，也可以依話題篩選並做話題測驗。另有生詞本、依錯誤類型分組的錯題本，以及易混淆字的對比卡與對比測驗。
- **我的**：顯示各題型的正確率，並建議要加強的項目。另外可以設定發音（英式或美式口音、聲音、語速）和深淺色，也能匯出、匯入進度。

## 檔案
- `index.html`、`style.css`、`app.js`：網頁本體，純靜態，不需建置。
- `data/dict.json`：3,850 個單詞的例句（附中譯）、詞性、詞族、搭配、同義字、反義字、易混淆字和話題，由 Claude 依故事中的中文釋義產生。
- `data/stories.json`：從 `雅思單詞/` 的學習版 PDF 和重點單詞.xlsx 解析出來的資料。
- `tools/parse_stories.py`：重新產生資料的腳本，用法：`python3 tools/parse_stories.py 雅思單詞 data/stories.json`，需要 `pdftotext` 和 `openpyxl`。

## 本機預覽
```
python3 -m http.server
```
然後打開 http://localhost:8000
