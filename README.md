# 霸總雅思單詞

用 100 個霸道總裁故事背雅思單詞的手機互動學習網頁。

## 功能
- **故事閱讀**：三種模式
  - 學習：中英對照
  - 複習：看英文回想中文
  - 挑戰：看中文回想英文
- 點任一單詞可以看釋義、故事原句、英文例句、同義和反義字，聽發音，也能加入生詞本或標記已掌握。
- 發音可以選英式或美式口音、手機上的聲音，以及語速。
- **單詞卡**：翻面記憶，左右滑動標記認識或不認識。
- **測驗**：四種題型，分別是看英文選中文、看中文選英文、故事填空和拼寫。答錯的單詞會自動進錯題本。
- **單詞本**：3,850 個不重複單詞可以搜尋，還有生詞本、已掌握篩選。
- **我的**：顯示學習進度、連續天數和深淺色設定，進度可以匯出或匯入。進度存在手機瀏覽器裡。

## 檔案
- `index.html`、`style.css`、`app.js`：網頁本體，純靜態，不需建置。
- `data/dict.json`：3,850 個單詞的英文例句（附中譯）、同義字、反義字，由 Claude 依故事中的中文釋義產生。
- `data/stories.json`：從 `雅思單詞/` 的學習版 PDF 和重點單詞.xlsx 解析出來的資料。
- `tools/parse_stories.py`：重新產生資料的腳本，用法：`python3 tools/parse_stories.py 雅思單詞 data/stories.json`，需要 `pdftotext` 和 `openpyxl`。

## 本機預覽
```
python3 -m http.server
```
然後打開 http://localhost:8000
